A broadsheet-style single image summing up Tuesday 24 November 2026 in world news: 38 stories, 13 illustrated leads, a UTC timeline, key numbers, and a world map with numbered pins. Original drawings only, no photos.

Built for the make.fun bounty "Sum up 24 November's world news in one image" (news-image-20261124).

The image is rendered by `draw.py` (Python + Pillow, DejaVu fonts) and `main.ts` copies the finished `entry.png` (1024×1024) to the output directory.
